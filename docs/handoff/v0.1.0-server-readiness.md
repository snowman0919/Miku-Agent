# V0.1.0 Server Readiness Handoff

이 체크리스트는 V0.0.1 완료 후 V0.1.0에서만 실행한다. V0.0.1 중에는 서버 접속, model access/download, GPU inference를 하지 않는다.

## Entry evidence

- 비공개 `snowman0919/Miku-Agent` repository의 annotated `v0.0.1` tag를 source lock으로 checkout한다. `main latest`를 source로 사용하지 않는다.
- Repository, tag, tag object SHA, peeled release commit, manifest의 definition commit, release-manifest SHA-256, product-lock SHA-256과 accepted ADR inventory를 run binding에 기록한다.
- Product lock과 accepted ADR을 읽고 experiment가 decision을 조용히 바꾸지 않도록 run ID에 연결한다.

## Server inventory

- RTX 5090 GPU model/VRAM, CPU, system RAM, disk free/throughput를 기록한다.
- OS/kernel, NVIDIA driver, CUDA runtime, Docker/runtime version과 compatibility를 기록한다.
- VoiceChat license, gated access 조건과 계정 authorization을 확인한다.
- 허용된 checkpoint를 download한 뒤 source revision과 cryptographic hash를 기록한다.

## Reference run

- Vendor/reference 절차로 baseline inference를 실행하고 command/config/log를 보존한다.
- Load/idle/prefill/decode/stream 단계의 VRAM과 RAM peak를 profile한다.
- STT partial, response TTFA, TTS first audio, end-to-end latency를 trace ID로 측정한다.
- 30분 soak 동안 memory growth, thermal, error/reconnect를 기록한다.
- Tool channel의 valid/malformed request를 검사하되 실제 side effect 권한은 부여하지 않는다.

## Failure report

재현 command, exact environment, checkpoint hash, expected/actual, log, resource profile, attempted mitigation과 scope-safe next experiment를 포함한다. 적재 또는 실행 실패도 성공적인 feasibility evidence가 될 수 있으나 baseline inference를 성공으로 표시해서는 안 된다.

## Exit

Reproducible reference baseline과 capacity/latency risk update가 있거나, blocked 원인과 필요한 권한·hardware·upstream fix가 명확해야 한다. 그 전에는 dataset/tuning 단계로 넘어가지 않는다.
