## Source Separation

단일 known-mixture 후보 비교에서 htdemucs / umxhq vocal SI-SDR은 각각 22.7759 /
17.8476 dB였다. htdemucs 선택 후 10개 known-mixture에서 47.9405초를 5.7275초에
처리했고 vocal SI-SDR 평균은 21.9759 dB였다. 낮은 음악 gain 때문에 instrumental
SI-SDR -10.1275 dB는 일반 음악 분리 정확도로 일반화하지 않는다. Ground-truth stem이
있는 synthetic fixture에서만 SI-SDR을 사용했다.

## ASR

Whisper / MMS는 각각 같은 50개, 총 245.9364초의 generated Korean speech를 처리했다.
CER는 0.3529 / 0.5625, 처리 RTF는 0.01129 / 0.00313이었다. MMS가 빠르지만 품질과
CC-BY-NC-4.0 제약 때문에 reject하고 Whisper를 잠정 default로 선택했다. Human Korean,
Miku-like voice, Japanese, code-switch, long speech와 singing-derived vocal은 미측정이다.
Worker는 hypothesis를 canonical transcript로 확정하지 않는다.

## Alignment

MMS CTC와 `torchaudio.functional.forced_align`로 known transcript 20개를 처리했다.
Word/token interval, confidence, unaligned span, duration anomaly를 반환했고 실패율은
0이었다. Phoneme timing은 지원하지 않는다. 기술 pilot은 성공했지만 비상업 license라
default integration은 `BLOCKED`다.

## Speaker

SpeechBrain ECAPA와 X-vector를 50개 generated single-speaker variation에서 비교했다.
X-vector는 512차원 L2 embedding, pairwise mean/min 0.9840/0.9657, centroid mean/min
0.9921/0.9823이었다. 실제 Miku gold corpus와 negative speaker가 없어 arbitrary
threshold를 만들지 않았고 consistency API 상태는 `NOT CALIBRATED`다.

## Quality and Prosody

Quality는 duration, peak, RMS, DC offset, clipping, zero-crossing, noise-floor와 SNR
proxy를 component별로 반환하며 단일 canonical score를 만들지 않는다. Prosody는
frame별 F0 contour, energy, voiced/unvoiced, pause interval, pitch range, duration과
speaking-rate proxy를 보존한다. 두 결과 모두 calibration되지 않았다.

## 3080 Integration

Job/result package는 filesystem transport이며 scp/rsync 전후 hash 검증이 가능하다.
3080 측에는 idempotent importer가 필요하다. Importer는 result schema/status, manifest와
각 output hash를 재검증하고 transform fingerprint/environment/job ID를 보존한 뒤,
별도 canonical policy와 human review에서만 rights/training/split 결정을 해야 한다.
현재 branch는 3080 DB나 object store를 수정하지 않았다.
